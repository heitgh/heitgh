### What if the browser adapted to the user, instead of forcing the user to adapt to the browser?

Moon is an open-source desktop browser built on **Electron and Chromium**. It explores a more ergonomic, contextual and personal way to navigate — keeping control with the user while moving carefully toward native AI capabilities.

- **Digital ergonomics** — less visual friction and more comfortable long sessions.
- **Deep personalization** — an interface shaped around individual preferences.
- **Contextual productivity** — tabs, workspaces and tools organized around intent.
- **Privacy and control** — explicit decisions, local-first foundations and human oversight.
- **Responsible AI direction** — intelligent features introduced only when they are real, useful and permission-aware.
